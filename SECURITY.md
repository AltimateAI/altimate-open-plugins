# Security policy

Do not report vulnerabilities, credentials, customer data or other sensitive details in a public issue or comment.

If GitHub private vulnerability reporting is enabled for this repository, use **Security > Report a vulnerability**. Otherwise, contact your Altimate representative through an existing private support channel. Include only the detail needed to reproduce and assess the issue, and use a secure private channel for any sensitive follow-up.

If a secret is exposed, revoke or rotate it immediately through the system that issued it, then report the exposure privately.
