# Contributing

This repository accepts issues only. It does not take pull requests; any pull request will be closed without review.

Open an issue for a bug, a wrong or missing skill instruction, or a request. Say which client you use (Claude Code or Codex), the plugin version, and what you expected.

## Keep issues safe to read

Everything in an issue is public. Do not include:

- Credentials, API keys or access tokens.
- Real customer or tenant names, identifiers, data or cost figures. Use clearly synthetic examples.
- Internal-only URLs, configuration captures or logs you have not reviewed.

Redact secrets before you post. Editing an issue later does not remove the earlier text from its history.

The plugin needs an Altimate tenant and your own Altimate API key. Where the repository is hosted does not change authentication, authorization or access controls.

To report a vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
